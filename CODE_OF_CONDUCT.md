# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1:
be respectful, welcoming and constructive in every project space, and wherever you represent the project. Report unacceptable
behavior to conduct@reportix.com. The community leaders review every report promptly and fairly, respect the reporter's privacy,
and follow the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
